LAB DOCUMENTATION

Home Network Vulnerability Assessment

Objective

Establish a comprehensive defensive audit of an active Small Office/Home Office (SOHO) network to identify open service vectors, weak credentials, and legacy configurations before potential adversaries can exploit them.

Step-by-Step Methodology

  • Subnet Mapping: Executed ARP broadcast sweeps across the 192.168.1.0/24 subnet to identify all connected nodes (workstations, mobile devices, router, smart TVs).
  • Stealth SYN Scanning: Used nmap -sS -sV -O -p- 192.168.1.1 to detect open ports without establishing full TCP handshakes.
  • Vulnerability Script Auditing: Ran custom NSE scripts (--script vuln,default) to cross-reference exposed daemon banners with known CVE databases.
  • Remediation Implementation: Disabled unencrypted Telnet/HTTP management interfaces, migrated router admin access to HTTPS, segmented IoT devices onto a guest VLAN, and updated router firmware.

Key Remediation Findings

FINDING 1

UPnP (Universal Plug and Play) was enabled by default on the gateway, allowing unverified port mapping.

Action: Disabled UPnP globally
FINDING 2

WPA2-PSK weak pre-shared key susceptible to offline dictionary cracking.

Action: Upgraded to 24-char entropy key + WPA3
